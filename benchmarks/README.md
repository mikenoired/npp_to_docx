# Результаты миграции и оптимизации

Apple M1, macOS 27.0.1, Rust 1.98.0. Один набор из 1410 SVG и двух подготовленных CSV; concurrency=2.

| Метрика | Electron | Rust + GPUI |
|---|---:|---:|
| Обработка 1410 SVG | 87,82 с | 46,26 с |
| Пиковая RSS обработки | 925,52 МБ | 189,56 МБ |
| Размер приложения | 335,37 МБ | 15,57 МБ |
| Чистая сборка (исходный замер миграции) | 2,95 с | 196,23 с |
| Повторная сборка без изменений | 1,87 с | 0,40 с |
| Общий размер DOCX | 224,28 МБ | 237,33 МБ |

Время обработки и RSS — медианы трёх свежих прогонов каждой реализации. Rust теперь тратит на обработку на 47,33% меньше времени, чем Electron (ускорение в 1,90 раза). RSS ниже на 79,52%, приложение меньше на 95,4%. МБ указаны в десятичной системе.

## Причина и исправление

Раньше Rust обрабатывал набор за 101,09 с. Файловые шрифты в fontdb заново открывались и отображались в память при обработке отдельных символов. Теперь выбранные шрифты загружаются в разделяемую память один раз за пакет, результаты выбора шрифта кешируются. Новых зависимостей нет. Время обработки Rust сократилось на 54,24%.

Проверены все 1410 DOCX относительно предыдущей версии Rust: файлы DOCX целиком и вложенные PNG идентичны побайтно. Сохранены параметры отрисовки, шрифты, разрешение и кодирование PNG. DOCX занимают на 5,8% больше места, чем у Electron; это осталось с первоначальной миграции.

## Условия и проверки

Сравнивались движки через CLI: Electron запускался с `ELECTRON_RUN_AS_NODE=1` на встроенном Node v22.21.1; Rust — через release-бинарник. Окна GUI исключены из обоих замеров RSS.

Чистая сборка измерена один раз при первоначальной миграции и после оптимизации не повторялась. Она включает компиляцию зависимостей Rust; Electron использует предсобранные Electron и sharp. Установка зависимостей исключена. Повторная сборка выполнялась без изменения исходников; замер Rust и размер пакета обновлены.

Повторно проверены все 1410 DOCX относительно Electron: тексты, таблицы, цвета несовпадений, размеры страницы/рисунков, отчёты ресурсов и поисковые записи совпадают. Проверены 85 603 маркера и 10 383 несовпадения. Все изображения прошли отдельный допуск MAE ≤ 10 из 255: среднее 0,923, максимум 6,570. Пиксели Electron и Rust не идентичны из-за различий растровых движков.

Десять тестов, Clippy, сборка и упаковка: [CI для Linux, Windows и macOS](https://github.com/mikenoired/npp_to_docx/actions/runs/38057475644).

Исходные данные и DOCX находятся в игнорируемой `output/`. Последний результат: `output/rust-optimized/`. Отчёты: `output/full-parity.json`, `output/optimization-parity.json`, `output/optimization-image-bytes.json`. Предыдущие замеры сохранены в `history/`; команды, хеш набора и отдельные прогоны — в JSON.
