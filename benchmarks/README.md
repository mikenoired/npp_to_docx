# Результаты миграции

Apple M1, macOS 27.0.1, Rust 1.98.0. Один набор из 1410 SVG и двух подготовленных CSV; concurrency=2.

| Метрика | Electron | Rust + GPUI |
|---|---:|---:|
| Обработка 1410 SVG | 81,56 с | 101,09 с |
| Пиковая RSS обработки | 1206,37 МБ | 167,74 МБ |
| Размер приложения | 335,37 МБ | 15,55 МБ |
| Чистая сборка | 2,95 с | 196,23 с |
| Повторная сборка без изменений | 1,87 с | 0,55 с |
| Общий размер DOCX | 224,28 МБ | 237,33 МБ |

Время обработки, RSS и повторная сборка — медианы трёх прогонов. Чистая сборка измерена один раз. МБ указаны в десятичной системе.

Обработка в Rust медленнее на 23,9%; RSS ниже на 86,1%, приложение меньше на 95,4%. DOCX занимают на 5,8% больше места из-за другого растрового движка и кодирования PNG.

Сравнивались движки через CLI: Electron запускался с `ELECTRON_RUN_AS_NODE=1` на встроенном Node v22.21.1; Rust — через release-бинарник. Окна GUI исключены из обоих замеров RSS.

Чистая сборка Rust включает компиляцию зависимостей; Electron использует предсобранные Electron и sharp. Установка зависимостей исключена. Повторная сборка выполнялась без изменения исходников.

Все 1410 DOCX совпадают по текстам, таблицам, цветам несовпадений, размерам страницы/рисунков, отчётам ресурсов и поисковым записям. Проверены 85 603 маркера и 10 383 несовпадения. Все изображения прошли отдельный допуск MAE ≤ 10 из 255: среднее 0,923, максимум 6,570. Пиксели не идентичны; различия отрисовки шрифтов остаются. Кадры с наибольшими отличиями просмотрены вручную.

Девять тестов, Clippy, сборка и упаковка прошли на macOS, Linux и Windows: [CI](https://github.com/mikenoired/npp_to_docx/actions/runs/38054194643). Окно GPUI дополнительно запущено и осмотрено на macOS.

Исходные данные и DOCX находятся в игнорируемой `output/`. Полный отчёт сравнения: `output/full-parity.json`. Команды, хеш набора и отдельные прогоны сохранены в JSON в этой папке.
