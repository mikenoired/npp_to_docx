# complete-frames
Статус: реализация.

## Цель и источник
Запрос пользователя: кадры без недостающих ресурсов, логически дорисовать отсутствующее, все изменения в Git. Под видеокадрами понимаются статические технологические SVG-кадры текущего приложения. Риск обычный: экспорт документации, без управления оборудованием. Условные изображения явно обозначаются, измерения, логика защиты и состояния не выдумываются.

## База и область
753c4b8 + изменения предыдущего этапа (README, svg-resources, passport.test, tasks/vm-submodels). Поток: локальные библиотеки → разрешение изображений/вложенности → SVG с встроенными изображениями → PNG → DOCX и отчет. Упаковать библиотеку в assets, подключить одинаково из исходников/build/дистрибутива; сохранить приоритет локальных оригиналов.

## Матрица и проверки
Нормальный оригинал → сохраняется; отсутствующий известный ресурс → явно условная графика; неизвестный → прежняя заглушка и отчет; сеть/../ → отклоняются; legacy Windows путь → только basename из локальной библиотеки; вложенные изображения и цикл → текущая ограниченная рекурсия; 1410 кадров → полный прогон; повтор → воспроизводим; параллельность → чтение assets; ошибочный SVG → ошибка кадра, исходники сохраняются. Старые DOCX не перезаписывать, результат в новой папке.

Минимальное решение: каталог assets/submodels с перенесенной библиотекой и 18 условными ресурсами, без новых зависимостей; пояснение реконструкций в DOCX/JSON, экспорт готового SVG. Применяется ponytail. Проверки: baseline, regression, npm run check/build, полный batch, XML всех экспортов и визуальная проверка измененных элементов. Самопроверка требований и реализации отдельно. Внешний PR обновляется в ранее используемой ветке, слияние не требуется.
