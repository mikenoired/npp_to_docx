## Самопроверка и ограничения
Проход требований: все доступные ресурсы перенесены, все 18 недоступных имеют
условные изображения, новые кадры с неизвестными ресурсами сохраняют отчет о
пропусках. Проход реализации: старый API сохранен, локальные оригиналы приоритетны,
рекурсия ограничена, пути не позволяют читать произвольные абсолютные файлы,
исходные кадры защищены от перезаписи. Новых runtime-зависимостей нет.
Самопроверка не является независимым ревью; для обычного риска оно не требуется.
Изменения фикстур расширяют проверку по запросу пользователя, не ослабляют приемку.
Локально проверен macOS core. GUI и Windows/Linux здесь не собирались; UI не менялся,
GUI использует этот же batch. Полная визуальная проверка всех 1410 документов не
выполнялась. Изображения статические, ПОРТАЛ-скрипты, показания и состояния не исполняются.
Исходные ВМ, базы, кадры и сгенерированные паспорта не включены в Git.
Исходные SVG библиотеки содержат CRLF и пробелы на концах строк. Начальный diff --check
отметил эти vendor-байты; .gitattributes исключает для них проверку конечных пробелов
и преобразование строк, чтобы сохранить SHA-256 оригиналов. Проверка исходников
программы не ослаблена. Финальный diff --check успешно проходит.
